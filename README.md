Установка зависимостей:
Зависимости управляются через Maven и скачиваются автоматически при первой сборке
(./mvnw test или ./mvnw package). 
Устанавливать их вручную не нужно.
Требуется только JDK 21.

Используемые библиотеки:
junit-jupiter версия 6.1.3  Модульные тесты (область test)


Архитектура и решения:

Этапы разработки:
1. создание проекта на Maven, создание удаленного репозитория и клонирование его на локаль
2. подключение библиотеки для тестов JUnit и запускающего ее плагина
